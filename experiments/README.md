# Experiments & Research Sandbox

This directory is designated for all future strategy experiments, parameter optimizations, Machine Learning filters, and feature prototypes.

## Rules:
1. **Isolated Testing**: Do not modify files in the repository root. Create your test scripts inside experiments/<experiment_name>/.
2. **Backtesting**: Validate all new ideas against historical ticks and out-of-sample data.
3. **Promotion**: Once an experiment proves statistically superior with lower drawdown and higher Sharpe ratio, it can be proposed for production promotion.
